# KnowledgeOps Architecture Decision Records

All decisions below are accepted as of July 9, 2026.

- ADR-001: Google Sheets is the initial operational UI
- ADR-002: Page_ID is the immutable identifier
- ADR-003: Separate authored and audit-derived metadata
- ADR-004: Document rules before automating them
- ADR-005: GitHub is canonical for engineering truth
- ADR-006: Notion is canonical for living operational documentation
- ADR-007: Human decisions override automated recommendations
- ADR-008: Every audit run is preserved as an immutable snapshot
- ADR-009: Rules and quality checks are separate layers
- ADR-010: Programmatic page writes require reversible pilot testing

Each ADR should eventually be maintained as an individual Markdown file with status, context, decision, alternatives, and consequences.
