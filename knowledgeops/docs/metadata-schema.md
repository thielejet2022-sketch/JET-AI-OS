# KnowledgeOps Metadata Schema

## Human-Assigned Metadata

- Owner
- Status
- Content Type
- Project
- Canonical
- Last Reviewed
- Review Cadence
- Sensitivity

## Audit-Derived Metadata

- Page_ID
- Breadcrumb
- Top_Level
- Section
- Sub_Section
- Depth
- Last_Edited
- Edit_Bucket
- Is_Orphaned
- Is_Interview
- Duplicate_Count
- Naming_Rule
- Recommended_Action
- Snapshot_Date

## Human Workflow Metadata

- Decision
- Owner_Assigned
- Notes
- Done
- Decision_Date

## Design Rule

Audit-derived metadata remains outside the Notion page unless it is intentionally promoted into authoritative governance metadata.

Page_ID is the immutable identifier for snapshots and comparisons.
